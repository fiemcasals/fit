tiene que tener usuario, paraque sea escalable, pudiendo crearse muchos usuarios(profes). Cada profe crea sus clases con dias y horarios. y desp crea la lista de alumnos para cada clase. La idea es que una vez creado, llegado el momento de la clase, el profe pueda tildar a los presentes, y finalmente genera un reporte. Voy a adjuntar las notas que actualmente toma el profe para tomar listas, la plantillaque se debe completar, y como esta quedando actualmente. Se puede observar que saca la cantidad de alumnos hombres y mujer de la clase(uno en general). y los presentes de cada clase, (sin discriminar el sexo). Finalmente va la firma, y se debe poder exportar un pdf y enviar un correo.
dentro del stack tecnologico: dockerizado, con base de datos postgress. usando react y django
